Как устанавливать приложения

iPhone / iPad (без джейлбрейка)

  1. Установи SideStore или AltStore
  2. Скачай IPA файла приложения (если доступен)
  3. Открой SideStore → «+» → выбери IPA
  4. Подпиши своим Apple ID (бесплатно, 7 дней)
  5. Для постоянного — LiveContainer или платный сертификат

Android

Просто скачай APK и разреши установку из неизвестных источников. Или используй F-Droid для открытого ПО.

Windows / macOS / Linux

Скачивай установщики с официальных страниц проектов (GitHub Releases). Для Linux — пакетные менеджеры или AppImage/Flatpak.
