Как устанавливать

iPhone / iPad (без джейлбрейка)

  1. Установи SideStore или AltStore
  2. Скачай IPA (если приложение его предоставляет)
  3. В SideStore нажми «+» и выбери файл
  4. Подпиши своим бесплатным Apple ID (обновление каждые 7 дней)
  5. Для большего количества приложений используй LiveContainer

Android

Скачай APK → разреши установку из неизвестных источников. Лучший источник открытого ПО — F-Droid.

Windows / macOS / Linux

Скачивай с официальных страниц проектов (обычно GitHub Releases). На Linux удобны Flatpak, AppImage и родные пакетные менеджеры.

О проекте

UniversalAppStore — каталог свободного и открытого программного обеспечения для всех популярных платформ.

Мы включаем только приложения с открытым исходным кодом или полностью бесплатные легальные программы. Коммерческие закрытые приложения (платные игры, Adobe, Microsoft Office и т.д.) нельзя легально раздавать бесплатно — это нарушение авторского права. Для них мы можем указать официальный сайт, но не «скачать бесплатно».

Поиск сделан максимально умным: учитывает название, описание, теги, платформу, синонимы и частичные совпадения.
