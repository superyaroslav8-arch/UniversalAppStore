# UniversalAppStore

**Free open-source universal app discovery platform** with smart AI-powered search.

Discover free and open-source applications for:
- iPhone / iPad (iOS / iPadOS)
- Android
- Windows
- macOS
- Linux
- watchOS / Apple Watch
- tvOS / Apple TV
- visionOS
- Web / PWA

## Features
- Smart relevance search (name + description + tags + platform)
- Categories and platform filters
- Direct links to source / downloads where available
- Installation guides for sideloading on iOS
- Fully client-side, works offline after load
- Modern dark UI

## Live
Open `index.html` or enable GitHub Pages.

## Legal
This store only catalogs **free and open-source** software. No pirated or commercial apps are hosted or distributed. Always respect licenses and copyrights.

Built for education and legitimate discovery.
